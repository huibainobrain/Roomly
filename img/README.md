# 首页图片素材

把做好的图片按下面的文件名放进这个目录即可，页面会自动显示。
文件不存在时页面显示浅色占位块，不会报错也不会塌陷。

| 文件名 | 用途 | 建议尺寸 | 说明 |
|---|---|---|---|
| `home-welcome.png` | 顶部欢迎横幅右侧氛围图 | 1200×640（约 15:8） | 窗边阳光、绿植、桌椅。主体略偏右，左侧留空以便与文字衔接 |
| `home-mood.png` | 「今天，家里怎么样」主视觉 | 1120×630（16:9） | 沙发、猫、绿植、午后光线。四周留边，会被裁成 16:9 |
| `home-lifeband.png` | 底部生活方式横幅 | 2400×420（约 40:7） | 横向通铺，中间会压一行文字，中央区域请留浅色、不要放主体 |
| `nav-corner.png` | 左侧导航底部装饰 | 640×512（5:4） | 猫 + 绿植 + 坐垫。窄栏显示，主体居中 |
| `avatar-yiming.png` | 成员头像 | 400×400 正方 | 会被裁成圆形，脸部居中，边缘留安全区 |
| `avatar-alex.png` | 成员头像 | 400×400 正方 | 同上 |
| `avatar-tom.png` | 成员头像 | 400×400 正方 | 同上 |

## 注意事项

- 全部使用 `object-fit: cover`，会按容器比例居中裁切，主体请放在画面中央
- 横幅类图片不要把业务文字画进图里，文字全部由代码渲染
- 背景建议贴近奶油白 `#FCF8F1` / 浅沙 `#F5EDE0`，与页面衔接更自然
- 不需要透明背景；如果用透明 PNG，注意页面底色在深色模式下会变深
- 单张建议控制在 300KB 以内，可用 WebP（改文件名后缀同时改 views.js 里的路径）
