## 注意事项

- 全部使用 `object-fit: cover`，会按容器比例居中裁切，主体请放在画面中央
- 横幅类图片不要把业务文字画进图里，文字（金额、人名、任务）全部由代码渲染
- 背景建议贴近奶油白 `#FCF8F1` / 浅沙 `#F5EDE0`，与页面衔接更自然
- `avatar-lin` 原始素材是透明底抠图，已合成到 `rgb(252,240,217)` 奶油底，
  与另外三张头像的背景保持一致；换图时如果仍是透明 PNG，圆形头像会透出成员色
- 用 JPEG 而不是 PNG：同样画质下体积约为 PNG 的 1/5（全部 8 张合计约 550KB）。
  换成其他格式时记得同步改 `js/data.js`（头像）、`js/views.js`（三张首页图）、
  `index.html`（侧栏装饰图）里的路径
