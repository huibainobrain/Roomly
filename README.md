# 合租生活管家 · Shared Flat OS

面向年轻合租人群的共享生活管理工具。让合租中的**费用、责任、物品和规则**公开透明、可追溯，并由系统承担提醒职责，降低室友之间的沟通成本。

Demo 空间：**Jurong West 503**　成员：Yiming / Alex / Tom

## 功能模块

| 模块 | 说明 |
|---|---|
| 首页 | 「今天需要处理什么」— 值日 / 费用 / 物品 / 公约 四类待办卡片、本月概览指标、最近动态 |
| 费用 | 公共支出记录，按参与人自动平均分摊（AA），可标记已结清 |
| 值日 | 本周责任到人，一键标记完成；附按成员顺序轮换的下周排班 |
| 物品 | 公共物品库存增减，低于提醒阈值自动标记「库存不足」 |
| 公约 | 室友规则记录，三人全部确认后生效 |

## 跨模块联动

这不是五个独立页面，而是一个共享生活管理系统：

1. 首页完成值日 → 值日模块状态同步 → 最近动态新增记录
2. 物品模块补充厕纸 → 首页低库存提醒消失
3. 补充物品并填写购买金额 → **费用模块自动生成一笔三人 AA 的公共支出**
4. 公约确认 → 首页待确认提醒消失
5. 所有导航的红点数量随状态实时变化

## 技术说明

当前为限时产品雏形（MVP）阶段，聚焦产品思路与交互完整性：

- 零构建依赖的单文件静态页面，秒级部署、无冷启动
- 原生 JS 状态驱动渲染，所有模块共享同一份状态，保证跨模块联动
- `localStorage` 持久化，刷新后数据保留；左下角可重置演示数据
- 响应式：桌面端左侧导航，移动端底部标签栏
- 深浅色主题自适应（跟随系统，亦响应显式主题设置）

暂未实现（本阶段有意省略）：登录注册、后端与数据库、真实支付、消息推送、多空间管理。
